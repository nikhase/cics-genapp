# Learning Plan

## Backend (Spring Boot)
- Complete Spring Boot guides: REST service, validation, data access with JPA.
- Study Flyway migration patterns and Testcontainers integration.
- Practice building JWT-secured endpoints with Spring Security.

## Frontend (React)
- Work through React docs on hooks, routing, and forms.
- Learn React Query for data fetching and caching.
- Explore component styling via Tailwind or Chakra UI.

## Database & Data Migration
- Review PostgreSQL fundamentals (datatypes, indexing, transactions).
- Map COBOL copybooks to relational schemas; prototype conversions with scripts.
- Experiment with pgLoader or custom ETL for legacy data ingestion.

## DevOps & Tooling
- Deepen Docker knowledge (multi-stage builds, Compose overrides).
- Set up GitHub Actions workflows for lint/test/build.
- Later: practice with Kind or Minikube to deploy the containers on Kubernetes.

## Observability & Quality
- Learn OpenAPI/Swagger documentation via Springdoc.
- Add Micrometer metrics and evaluate Prometheus/Grafana basics.
- Explore Cypress for UI end-to-end tests and Pact or Spring Cloud Contract for API contracts.

Track progress by annotating this file with completion dates, notes, and resources that were most helpful.
