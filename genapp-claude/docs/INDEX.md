## 💡 Key Concepts

### Java 21 Records
```java
public record CustomerDTO(
    Long customerId,
    String firstName,
    String email
) {}
```
- Immutable by default
- Auto-generates equals/hashCode/toString
- Perfect for DTOs

### Sealed Classes (coming)
```java
public sealed class Policy permits MotorPolicy, HousePolicy, ... {}
```
- Restrict inheritance hierarchy
- Type-safe pattern matching
- Perfect for domain models

### Spring Data JPA
```java
public interface CustomerRepository extends JpaRepository<Customer, Long> {
    Optional<Customer> findByEmail(String email);
    List<Customer> searchByFullName(@Param("pattern") String pattern);
}
```
- Automatic CRUD operations
- Type-safe custom queries
- No SQL writing needed

### @Transactional
```java
@Service
@Transactional
public class CustomerService {
    // Auto-commit on success, rollback on exception
}
```
- Automatic transaction management
- No manual begin/commit/rollback
- Exception-safe

## 📞 Need Help?

### Common Issues

**Docker containers won't start?**
- Run: `docker compose logs backend`
- Check: `docker ps`
- Solution: `docker compose down -v && docker compose up -d`

**Port already in use?**
- Find process: `lsof -i :8080`
- Kill or use different port: `BACKEND_PORT=8081 docker compose up -d`

**Tests failing?**
- Run: `mvn clean test`
- Check: `mvn test -X` (debug mode)

**Swagger UI not loading?**
- Wait 30 seconds for backend to start
- Try: `curl http://localhost:8080/actuator/health`
- Check logs: `docker compose logs backend`
